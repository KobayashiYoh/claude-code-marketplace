# fetch-latest-stable

現在使用しているFlutter SDKのバージョンと、stableチャンネルの最新バージョンを比較し、アップデートの要否判断に必要な情報をまとめる。

## 手順

1. 現在のFlutter SDKバージョンを確認する。
   - `flutter --version` (FVM使用時は `fvm flutter --version`)。
   - プロジェクトが `fvm` を使っている場合は `.fvmrc` や `.fvm/fvm_config.json` 等も確認する。
2. stableチャンネルの最新バージョンを確認する(公式のリリースチャンネル情報を参照する)。
3. 現在のバージョンと最新stableバージョンにギャップがあるか確認する。ギャップが無ければその旨を報告して終了する。
4. ギャップがある場合、間のバージョンで発生したリリースノート・変更点を確認し、特に以下の観点で要約する。
   - 破壊的変更(Breaking Changes)
   - 非推奨化(Deprecations)
   - このプロジェクトで使われている主要パッケージ・API・プラットフォーム(Android/iOS/Web等)に関連しそうな変更
5. 要約をユーザーに提示する。SDK自体の更新作業(実際のアップグレードコマンド実行)は、ユーザーが希望した場合のみ別途行う(このスキルは調査・要約が主目的)。

## 注意事項

- バージョン間の差分すべてを網羅する必要は無く、このプロジェクトに影響しそうな変更を優先して要約する。
- FVMを使っているプロジェクトでは、SDK切り替え自体は `fvm install`/`fvm use` 等のFVMコマンドを使う前提で案内する。
