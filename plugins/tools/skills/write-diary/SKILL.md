# write-diary

`~/.claude/history.jsonl` からAIツールに関する初体験・学び・自動化の実践を抽出し、1行日記形式で追記する。

## 手順

1. 対象期間を確認する。指示が無ければ「前回の日記追記日時以降〜現在」をデフォルトとする。
2. 日記ファイルのパスを確認する。指示が無ければユーザーに保存先を尋ねるか、既存の日記ファイル(例: 過去にこのスキルで作成したもの)があればそれを使う。
3. `~/.claude/history.jsonl` を読み込む(1行1JSONのフォーマット)。対象期間に含まれるエントリのみを対象にする。
4. 各エントリの内容から、以下に該当するものを抽出する。
   - 初めて使ったAIツール・モデル・機能(例: 新しいスキル/コマンド/MCPサーバーを初めて使った)。
   - 明確な学び・気づき(例: 特定のプロンプトの工夫でうまくいった/いかなかった)。
   - 業務やプライベートの自動化を実践したもの(例: hookで自動化した、スキルを新規作成した)。
   - 単なるルーチン作業(通常のコーディング指示等、上記に該当しないもの)は対象外とする。
5. 抽出した内容を、日付ごとに1行(または数行)の簡潔な日記形式にまとめる。
   - 形式例: `YYYY-MM-DD: <要約(1文)>`
   - 同じ日に複数の学びがあれば、日付を1回書いた後に箇条書きで並べるか、複数行に分けて書く(既存の日記ファイルのフォーマットがあればそれに合わせる)。
6. 日記ファイルが既に存在する場合は末尾に追記する(既存内容を書き換えない)。存在しない場合は新規作成してよいかユーザーに確認する。
7. 追記した内容をユーザーに提示し、確認を求める。

## 注意事項

- `history.jsonl` には個人的なやり取りの詳細が含まれる可能性があるため、日記に書き出す内容は要約のみとし、機微な情報(トークン、パス中の個人情報等)をそのまま転記しない。
- 該当する学びが無い期間については「特記事項なし」等と書かず、その期間はスキップしてよい。
