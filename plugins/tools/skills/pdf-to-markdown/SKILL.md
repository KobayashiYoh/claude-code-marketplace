# pdf-to-markdown

PDF全体を一括で読み込み、章立て・見出し・表・箇条書きなどの構造を保ったMarkdownとして出力する。ページ単位のgrep/抜粋取得ではなく、全文をコンテキストに載せて以後の分析に使えるようにすることが目的。

## 手順

1. 対象PDFのパスを確認する。指示に無ければユーザーに確認する。
2. PDFのページ数を確認する。ページ数が多い場合(目安: 20ページ超)は、一度に読み込める範囲(最大20ページ程度)ごとに分割して読み込む。
3. 各範囲についてPDFの内容を読み込み、以下の方針でMarkdownに変換する。
   - 見出し(章・節)は `#`/`##`/`###` などの階層に変換する。
   - 表はMarkdownテーブル記法に変換する。崩れる場合は箇条書きで代替する。
   - 図・画像はキャプションのみをテキストとして残す(画像そのものは埋め込まない)。
   - ページ区切りが分かるよう、必要に応じて `<!-- page: N -->` のようなコメントを挟んでもよい。
4. 分割して読み込んだ場合は、変換後にすべてを結合して1つのMarkdownファイル(または1つの応答コンテキスト)にまとめる。
5. 出力先を確認する。ユーザーの指示が無ければ、入力PDFと同じディレクトリに拡張子を `.md` に変えたファイル名で保存してよいか確認してから保存する。
6. 変換後、目次(見出し一覧)を簡潔に提示し、ユーザーが以後の分析に着手しやすくする。

## 注意事項

- 部分的な抜粋やgrepでは文脈が失われる場合があるため、このスキルは常に全文を対象にする。
- スキャン画像PDF(OCR未実施)の場合は、可能な範囲でテキスト化を試みつつ、精度に限界がある旨をユーザーに伝える。
