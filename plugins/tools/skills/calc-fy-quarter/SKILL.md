# calc-fy-quarter

MTIグループの会計年度・四半期の慣習に基づき、当日時点の会計年度・四半期を算出する。

## 会計年度・四半期の定義

- 会計年度は10月起点。年度名はその会計年度が終わる年(9月が属する年)。
- 四半期の区分:
  - Q1: 10月〜12月
  - Q2: 1月〜3月
  - Q3: 4月〜6月
  - Q4: 7月〜9月
- 例: 2025年12月→`FY2026_Q1`、2026年1月→`FY2026_Q2`、2026年4月→`FY2026_Q3`、2026年7月→`FY2026_Q4`

## 手順

1. 以下のスクリプトを実行し、当日時点の`FY20XX_QX`形式の文字列を取得する。

   ```bash
   python3 <このスキルのディレクトリ>/calc_fy_quarter.py
   ```

2. 出力された`FY20XX_QX`をそのままユーザーへの回答や後続処理(SharePointのディレクトリ名等)に使用する。

## 注意事項

- MTIグループ固有の会計年度慣習(10月起点)に基づくロジックであり、他社では通用しない前提のスキルである。
- 日付は実行時点(`date.today()`)を基準にするため、過去・未来の任意日付を指定して計算したい場合はスクリプトを直接読んで同等のロジックを別途計算する。
