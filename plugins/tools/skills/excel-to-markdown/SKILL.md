# excel-to-markdown

Excelファイルの全シート(または指定シート)を読み込み、シートごとに独立したマークダウンテーブルファイルとして出力する。Excelのシート順を保持するため、ファイル名には連番プレフィックス(`{n}-`)を付与する。

## 前提

- `openpyxl` がインストールされていることを前提とする。無い場合は `pip3 install openpyxl` を案内して終了する。

## 手順

1. 入力Excelファイル(.xlsx)のパスを確認する。指示に無ければユーザーに確認する。
2. 出力先ディレクトリを確認する。指定が無ければ `temp` 配下に、Excelファイル名(拡張子なし)をサブディレクトリ名として出力する。
3. 見出しに参照ID・参照タイトル(チケット番号など)を付与したい場合は `--ref-id` / `--ref-title` オプションで指定する。省略時は付与しない。
4. 特定シートのみ変換したい場合は `--sheet` オプションでシート名を指定する。省略時は非表示(hidden/veryHidden)シートを除く全シートが対象になる。
5. 以下のコマンドで変換する。

   ```bash
   python3 ${CLAUDE_SKILL_DIR}/excel_to_md.py \
     --input "<入力Excelファイルパス>" \
     --outdir "<出力先ディレクトリ(省略時: temp)>"
   ```

   参照ID・タイトルや特定シートを指定する場合:

   ```bash
   python3 ${CLAUDE_SKILL_DIR}/excel_to_md.py \
     --input "<入力Excelファイルパス>" \
     --outdir "<出力先ディレクトリ>" \
     --ref-id "<参照ID>" \
     --ref-title "<参照タイトル>" \
     --sheet "<シート名>"
   ```

6. 出力された各mdファイルを `Read` ツールで確認し、テーブル形式が崩れていないか、データ行が欠損していないかを確認する。
7. 出力先ディレクトリ、変換したシート数・行数をユーザーに報告する。

## 変換仕様

- 各シートの最初の非空行をヘッダー行として扱う。
- セル内改行(`\n`)は `<br>` に変換する。
- 箇条書き記号(`・`)は `- ` に変換する。
- 数字箇条書き(`数字.`)は `数字. ` に変換する(スペース補完)。
- 2列目・3列目に登場する〃(同上マーク)は直前行と同じ値として復元しつつ、マークダウン上でも〃表示を保持する。
- データの無いシートは「（データなし）」と出力する。
- 出力ファイル名: `temp/{Excelファイル名}/{n}-{シート名}.md`(`n` はシート順の連番)。

## 注意事項

- `.xlsx` 形式のみサポートする(`.xls` は非対応)。
- 出力先に同名ファイルが既に存在する場合は上書きされる。
- 元のExcelファイルは変更・削除しない。
