# video-to-gif

入力動画を、ffmpegのパレット生成→パレット適用の2パス処理で高品質かつ軽量なアニメーションGIFに変換する。

## 前提

- `ffmpeg` がインストールされていることを前提とする。無い場合はインストール方法(例: `brew install ffmpeg`)を案内して終了する。

## 手順

1. 入力動画のパスを確認する。指示に無ければユーザーに確認する。
2. 出力先パスを決定する。指定が無ければ入力動画と同じディレクトリに、拡張子だけを `.gif` に変えたファイル名で出力する。
3. 必要に応じて、変換範囲(開始時刻・長さ)、フレームレート、幅(解像度)をユーザーに確認する。指定が無ければ元動画のフレームレートを基本としつつ、GIFが大きくなりすぎないよう妥当なデフォルト(例: fps=15、幅は元動画のまま or 適度に縮小)を採用する。
4. **1パス目(パレット生成)**: 動画の色情報から最適なパレットを生成する。

   ```bash
   ffmpeg -y -i <input> -vf "fps=<fps>,scale=<width>:-1:flags=lanczos,palettegen" <tmp_palette.png>
   ```

5. **2パス目(パレット適用)**: 生成したパレットを使ってGIFにエンコードする。

   ```bash
   ffmpeg -y -i <input> -i <tmp_palette.png> -filter_complex "fps=<fps>,scale=<width>:-1:flags=lanczos[x];[x][1:v]paletteuse" <output.gif>
   ```

6. 一時パレットファイルを削除する。
7. 出力ファイルのサイズを確認し、ユーザーに完了を報告する。サイズが大きすぎる場合(目安として数十MB超)は、fpsや解像度を下げて再変換するか確認する。

## 注意事項

- 入力ファイルが見つからない、またはffmpegが対応していない形式の場合はエラー内容をそのまま報告する。
- 元の動画ファイルは変更・削除しない。
