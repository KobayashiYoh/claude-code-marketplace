# create-branch

デフォルトブランチを最新状態にしたうえで、新しい作業ブランチを作成する。

## 手順

1. 現在のデフォルトブランチ名を確認する(`git symbolic-ref refs/remotes/origin/HEAD` または `git remote show origin` で確認できない場合はユーザーに確認するか、`main`/`master`のうち存在する方を採用する)。
2. `git fetch origin` を実行し、リモートの最新情報を取得する。
3. 現在ローカルに未コミットの変更が無いか `git status` で確認する。あれば、ユーザーに確認せずに破棄しない(必要ならstashを提案する)。
4. デフォルトブランチに切り替え、`git pull` で最新化する。
5. これから行う作業内容(ユーザーの指示・チケット内容など)から、内容を簡潔に表すkebab-case(小文字・ハイフン区切り)のブランチ名を生成する。
   - 例: 「ログイン画面のバリデーションを修正する」→ `fix-login-validation`
   - プロジェクト固有の命名規則(prefix等)がある場合は、引数でブランチ名またはprefixを明示的に指定できるようにし、指定があればそれを優先する。このスキル自体は外部設定ファイルを参照しない。
6. `git checkout -b <name>` で新しいブランチを作成する。
7. 作成したブランチ名を報告する。

## 注意事項

- デフォルトブランチの更新に失敗した場合(コンフリクト等)、無理にpullを進めずユーザーに状況を報告する。
- ブランチ名が空になる、または既存ブランチと重複する場合は、サフィックス(`-2`等)を付けるかユーザーに確認する。
