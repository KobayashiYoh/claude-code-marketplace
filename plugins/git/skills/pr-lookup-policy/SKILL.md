# pr-lookup-policy

review-code・explain-prなど、既存のPRを対象に処理を行うスキルが共通して行う「対象PRの特定」の方針をまとめる。このスキル単体はユーザーの指示で直接起動されることを想定せず、他スキルから参照される前提。

## 方針

1. ユーザーが引数やチャットでPR番号(またはURL)を明示的に指定している場合は、それを対象PRとする。
2. 明示指定が無い場合は、現在のブランチに紐づくPRを自動検出する。
   - Azure DevOpsの場合: `az repos pr list --source-branch <branch>` 等で検索する。
   - GitHubの場合(将来対応): `gh pr view --json number` 等で検索する。
3. 該当PRが複数見つかった場合、または1件も見つからない場合は、推測で決め打ちせずユーザーに確認する。

## 注意事項

- このスキルはPRの「特定方法」のみを扱う。特定後の処理(差分取得・コメント投稿・要約等)は呼び出し元スキル側の責務とする。
