# explain-pr

既存のAzure DevOps PRの内容を取得し、レビュアーや第三者向けに分かりやすく要約する。

## 設定の前提

組織名・プロジェクト名は他のAzure DevOps関連スキルと同様、プロジェクト側の設定ファイル(例: `.claude/ado.config.json`)・引数・環境変数から取得し、ハードコードしない。

## 手順

1. 対象PR番号を特定する。`pr-lookup-policy` の方針に従う。
2. `az repos pr show` でPRのメタ情報(タイトル・説明・作成者・マージ先ブランチ等)を取得する。
3. PRの差分を取得し、変更内容を把握する。
4. 以下の観点で説明を組み立てる。
   - このPRが解決しようとしている問題・目的
   - 主な変更点(ファイル単位ではなく機能・意図単位でまとめる)
   - 影響範囲・注意すべき点(あれば)
5. 説明をユーザーに提示する。技術的な詳細を求められた場合は、該当ファイル・行を示しながら補足する。

## 注意事項

- PRの説明文が既にある場合はそれを鵜呑みにせず、実際の差分と照らし合わせて過不足があれば指摘する。
